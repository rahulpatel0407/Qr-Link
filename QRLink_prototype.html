System Design

End-to-End Pipeline

A fully self-contained visual communication protocol — from raw file to recovered bytes, using only a screen and a camera.

Sender
01📂Select source file from device storage
02🗜Compress with Zstd / Brotli / Gzip
03🔐AES-256 encryption (optional)
04✂️Split into chunks with ID + CRC32
05⬛Generate Version-40 QR frames
06🎞️Display animated QR at 30–60 FPS
⬛
VISUAL
CHANNEL
📷
Receiver
07📷Capture frames via CameraX API
08🔍Decode QR data with ZXing + ML Kit
09🔁Track & recover only missing packets
10🧩Reassemble ordered chunks
11✅Verify SHA-256 checksum integrity
12💾Decrypt → Decompress → Save file

Core Features

Everything in the Build

Every feature listed in the project spec — compression, AI optimization, encryption, and real-time recovery.

⚡
Multi-Algorithm Compression
Automatically selects the best algorithm — Zstd, Brotli, or Gzip — based on file type to maximize the payload per QR frame.
COMPRESSION
🔐
AES-256 Encryption
Optional end-to-end encryption so files remain private even over a visual channel. Keys never leave the devices.
SECURITY
♾
Selective Retransmission
Receiver tracks only missing packets and requests retransmit without restarting the entire transfer — true packet-level recovery.
PROTOCOL
✅
SHA-256 Integrity Check
Every reassembled file is verified against its original hash. If a single bit flips, it's caught and the packet is re-requested.
VERIFICATION
🤖
AI Blur Detection
TensorFlow Lite model detects motion blur and camera shake in real-time, pausing capture and triggering automatic retries.
AI / TFLITE
🌙
Low-Light Enhancement
OpenCV preprocessing pipeline boosts contrast and clarity for scanning under dim conditions without additional hardware.
OPENCV
📐
Adaptive QR Density
QR version and error correction level adjust dynamically based on detected scan distance and ambient lighting conditions.
AI OPTIMIZATION
🎞️
30–60 FPS Animated Display
Smooth high-frame-rate QR animation engine ensures maximum throughput on devices capable of sustained 60 FPS rendering.
RENDERING
📦
CRC32 Packet Headers
Each chunk carries a packet ID, total count, and CRC32 checksum. Corrupt or partial packets are discarded cleanly and re-requested.
PROTOCOL
